# Часы для олимпиад — Android-обёртка (APK)

Зачем это нужно: на части интерактивных досок в системе **нет приложения, связанного
с файлом `.html`** — файл скачивается, но открыть его нечем. Здесь та же самая страница
лежит **внутри APK** (`assets/clock.html`), поэтому выбирать файл не нужно: нажал иконку —
часы на весь экран.

Это не копия логики: HTML внутри — тот же самый файл [`index.html`](../index.html) из корня
репозитория. Перед сборкой Gradle сам копирует его в `assets/clock.html`, так что APK не
отстаёт от страницы.

> **Готовый APK уже собран** — его можно взять в
> [релизах](https://github.com/RoBiN19666/olymp-clock/releases/latest) и не собирать самому.
> Инструкция ниже — если нужно собрать заново или что-то поменять.

## Что делает обёртка

- Открывает страницу в системном WebView, без адресной строки и меню.
- Полный экран: скрыты статус-бар и кнопки навигации (immersive sticky).
- **Не даёт экрану погаснуть** (`FLAG_KEEP_SCREEN_ON`) — важнее, чем Wake Lock API, который
  в WebView не работает.
- Включён `localStorage` — сохраняются название, время, тема и идущий таймер.
- Звук разрешён без первого клика (`setMediaPlaybackRequiresUserGesture(false)`).
- Системный размер шрифта Android не ломает вёрстку (`setTextZoom(100)`).
- Кнопка «Назад» закрывает приложение, поворот экрана не перезапускает страницу.
- **Работает выбор аудиофайла**: без `WebChromeClient.onShowFileChooser` кнопка «Выбрать файл»
  в WebView молча ничего не делает — это и была причина, почему на части устройств
  не получалось загрузить запись.
- **В списке недавних задач** показываются название и иконка приложения, а не заголовок
  страницы с пустым значком: `setTaskDescription()` задаёт их принудительно.
- **Проверка обновлений**: при запуске приложение спрашивает у GitHub последний релиз и,
  если там версия новее, предлагает обновиться. Загрузка — через системный `DownloadManager`,
  установка — через обычный установщик Android.
- Страница открывается с `?app=1`: кнопка «Во весь экран» и подсказка про `F` скрываются,
  потому что полный экран в приложении и так включён.
- Интернет не нужен; разрешения `INTERNET` и `ACCESS_NETWORK_STATE` — только для
  необязательной сверки времени и проверки обновлений.

## Сборка

Нужен [Android Studio](https://developer.android.com/studio) (бесплатный, ~1 ГБ).
Java и SDK ставить отдельно не надо — всё внутри студии.

1. `File → Open…` → выбрать **папку `apk`** (не отдельный файл).
2. Дождаться синхронизации Gradle (первый раз качает зависимости, нужен интернет).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Ссылка `locate` в уведомлении откроет папку с файлом:

```
apk/app/build/outputs/apk/debug/app-debug.apk
```

Этот APK уже подписан отладочным ключом — установить можно сразу. Размер получается
около 200–300 КБ (зависимостей нет вообще, только системный `android.webkit`).

### Если Android Studio нет

Нужны JDK 17 и Android SDK (cmdline-tools). Дальше из папки `apk`:

```
gradle wrapper --gradle-version 8.5
./gradlew assembleDebug
```

Проект без AndroidX и без внешних библиотек, поэтому собирается быстро и не тянет
ничего лишнего.

## Установка на доску

1. Скопировать `app-debug.apk` на доску (флешка, Wi-Fi, облако).
2. Открыть файл в файловом менеджере → «Установить».
3. Если система ругается — разрешить «Установка из неизвестных источников» для файлового
   менеджера. На многих досках это закрыто администратором: тогда APK поставить не выйдет,
   и остаётся вариант с локальным сервером по Wi-Fi.

## Обновление

1. Править только `index.html` в корне — при сборке он сам попадёт в `assets/clock.html`
   (задача `syncPage` в `app/build.gradle`).
2. При желании поднять `versionCode` / `versionName` в `app/build.gradle`.
3. `Build → Build APK(s)` → установить поверх старой версии (настройки сохранятся,
   они лежат в localStorage приложения и переживают обновление).

## Ограничения

- **Старый WebView никуда не денется.** APK использует тот же системный движок, что и
  браузер доски. Если движок совсем древний (Chrome < 60), вёрстка будет простой, но
  рабочей — в самой странице для этого есть резервные размеры.
- APK не устанавливается «сам» и не обновляется по воздуху — это файл, который вы
  распространяете вручную.
- На досках, где установка запрещена политикой, единственный рабочий путь — открыть часы
  по сети с ноутбука (`http://192.168.x.x:8000`).

```
├─ gradle/wrapper/gradle-wrapper.properties

   └─ src/main/
      ├─ AndroidManifest.xml        полноэкранная Activity, INTERNET
      ├─ assets/clock.html         ← сама страница с часами
      ├─ java/ru/robin19666/vsohclock/MainActivity.java
      └─ res/                      иконки (mipmap-*), тема, строки
```
